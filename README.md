## Local Development

### Prerequisites

* Node.js 20+
* npm / pnpm

### Installation

```bash
git clone <repository-url>

cd portfolio

npm install
```

### Start Development Server

```bash
npm run dev
```

### Build Production Version

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```
